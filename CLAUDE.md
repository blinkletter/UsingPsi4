# MystMD Book Project
- **Format:** This folder is a MystMD (MyST Markdown) web book, configured by `myst.yml` (`book-theme` template). Write content as MyST Markdown (`.md`) pages or Jupyter notebooks (`.ipynb`) and add each new page to the table of contents in `myst.yml`.
- **Chapter folders:** Each chapter has its own folder in `book/`, named by its two-digit prefix plus a name (e.g. `book/02-SmallMolecules/`). Files whose names start with the same two digits belong to that chapter (`021-...`, `022-...` both go in `02-...`). Run notebooks from their chapter folder so Psi4 `.out`, `.log`, `timer.dat` and JSON outputs stay beside the notebook, not in `book/` or the root.
- **Relative paths:** From a chapter folder, shared assets are two levels up: `../../images/`, `../../styles/`. Link to other chapters with `../<chapter-folder>/<file>`.
- **Syntax:** Use MyST directives and roles (admonitions, figures, cross-references, `{math}`/`$...$` equations, citations) rather than raw HTML.
- **Hosting:** The book is served via GitHub Pages from the `blinkletter/UsingPsi4` GitHub repository. Keep all links and figure paths relative so they work under the `/UsingPsi4/` base URL.
- **Build output:** `_build/` is generated by `myst build` — never edit it by hand or commit it.

# Plotting (matplotlib)
- **Style sheet:** Always apply `styles/tufte.mplstyle` (in this Psi4 folder) before plotting:
  ```python
  import matplotlib.pyplot as plt
  plt.style.use("../../styles/tufte.mplstyle")  # path from a book/<chapter>/ notebook
  ```
- **Object-oriented API only:** Create figures with `plt.subplots` and draw on the axes objects (`ax.plot`, `ax.set_xlabel`, etc.), never the `plt.plot` state-machine style. Start with:
  ```python
  fig, ax = plt.subplots(nrows=1, ncols=1, figsize=(5,4))
  ```
  For multiple panels use the same pattern, e.g. `fig, axs = plt.subplots(nrows=1, ncols=2, figsize=(9,4))`.
- **Lines:** Thin, `linewidth=0.5` or `0.7`.
- **Default markers:** Open circles — `marker="o"`, white fill, black thin outline:
  `markerfacecolor="white", markeredgecolor="black", markeredgewidth=0.5`.
- **Additional data series:** Also circles with thin outlines (`markeredgewidth=0.5`), filled with pastel colors, e.g.
  `["#AEC6CF", "#FFB3BA", "#BAFFC9", "#FFDFBA", "#CBAACB", "#FFFFBA"]`.
- **Fits behind data:** Draw fit/trend lines underneath the data points with `zorder` (e.g. fit `zorder=1`, points `zorder=2`).
- **Example:**
  ```python
  fig, ax = plt.subplots(nrows=1, ncols=1, figsize=(5,4))
  ax.plot(x_fit, y_fit, color="black", linewidth=0.7, zorder=1)
  ax.plot(x, y, linestyle="none", marker="o", markerfacecolor="white",
          markeredgecolor="black", markeredgewidth=0.5, zorder=2)
  ax.set_xlabel("x")
  ax.set_ylabel("y")
  ```
