# Table of Contents

Below is a list of the chapters in this book and a short description of each. 

[**1. Building Your System**](../01-Setup/011-Setup.md). Here you will be shown where to **obtain the software** and how to **install and run it** on a *MacOS Unix* system. These instructions should be easily applied to *Linux*. Essential ***Unix* tools** will be explained.

[**2. Water: Getting Started**](../02-SmallMolecules/021-SmallMolecules.ipynb). This chapter will introduce how to **run a job** in *Psi4*. We will explore the ways that molecules are described to *Psi4* in **input files**. We will see examples of using *xyz* **Cartessian coordinates** to describe the locations of atoms, using symmetry point groups so that we need only describe the symmetry unique atoms and using internal coordinates via the ***Z-matrix***. We will optimize the structures of **water and ammonia** using *Psi4*. We will use low-level *ab initio* methods and introduce the idea of **levels of theory** in calculations. *Psi4* will be run using a *Jupyter* notebook. **Results** will be interpretted using *Python* API and **log files** generated as output from *Psi4*.

[**3. Methane: Visual Input and Output**](../03-VisualInput/031-VisualInput.ipynb). Here we will see how to use the helper application ***Avogadro*** to build molecules and generate input files. We will also use *Avogadro* to **analyze** the results and **visualize** structure, localize *bonding orbitals* and *molecular orbitals*. 

[**4. Ethane: Symmetry in Calculations**](../04-Ethane/041-Ethane.ipynb). Sometimes you want to explore the structure and energies of unstable systems, like transition states. We need to **constrain the optimization** to find a best structure in a high-energy situation. In this chapter we will explore the rotational **energy profile** of ethane using **symmetry point groups** to enforce the *anti* and the *eclipsed* conformations. We will calculate the energy for these two cases.

[**5. Butane: Rotation Energy Profiles**](../05-RotationProfiles/051-RotationProfiles.ipynb). We can extend the idea of locking specific elements of a structure and performing a constrained optimization to explore the full **potential energy surface** for the rotation of the central C-C bond in butane. We will use **internal coordinates** (a Z-matrix) to set values of for the torsion angle  and **constrain** that value using the commands available in the *Python* API. Interactive ***Python*** will be used for **analyzing and plotting** the data.

[**6. Allyl Cation: &pi; Orbitals**](../06-PiOrbitals/061-PiOrbitals.ipynb). We have already used simplified Hückel molecular orbital theory and interactive *Python* to calculate the &pi;-molecular orbitals for **conjugated systems**. Now let us demonstrate that goal with *Psi4*. We will **calculate and visualize** the &pi;-molecular orbitals for the **allyl system** using *Psi4* and *Avogadro*. We will revisit the idea of using **symmetry** in calculations.

[**7. Benzene: MOs \& Symmetry**](../07-Benzene/071-Benzene.ipynb). We will explore **more** about &pi;-molecular orbitals and aromaticity using benzene as an example. Along the way we will use the **symmetry** of benzene to build it with a little *Python*, learn which point groups *Psi4* can use, and discover that how much symmetry speeds up a calculation **depends on the method**.

[**8. Butadiene: Transition State for Rotation**](../08-Butadiene/081-Butadiene.ipynb). We will use internal ***Z-matrix*** coordinates to create input files for **constrained optimization** of different rotational conformers of butadiene. Interactive *Python* will be used to analyze and plot the results. Then we will explore **optimizing a transition state** structure for the highest energy point in the bond rotation. 

[**9. Diels-Alder Reaction: Intrinsic Reaction Coordinates**](8A_Diels_Alder.md). We've all seen those little movies of a **reaction in progress**. We can make our own movies. We will use the Diels-Alder cycloaddition reaction as an example to demonstrate a **reaction coordinate scan** using **contrained coordinates**. We can then use this system to generate a **series of structures** that may track near the **reaction coordinate**. From this series we will identify a structure that is near the transition state and perform a **transition state optimization**. Finally we will use the transition state as a starting point for following the potential energy surface down to the products on either side via an **intrinsic reaction coordinate** calculation. We will use *Python* tools to assemble the complete reaction coordinate from the log files and **visualize** the structures and produce an **energy plot** for us. In the end, we will **make a movie**.

[**10. Solvent Models**](9_Solvent.md). Organic chemists do not live in **gas phase**. Our reactions occur in **solvents**. *Psi4* can include solvemnt effects through a variety of methods.  We will use the PCM method to **simulate a solvent environment** and observe the difference in calculations for an *S<sub>N</sub>2* reaction. We will again explore using **symmetry** to enforce geometry during optimization, **saddle point** optimization and **intrinsic reaction coordinate** calculations. This exercise will place an emphasis on using interactive *Python* tools to **process**, **clean** and **tabulate** the data.
