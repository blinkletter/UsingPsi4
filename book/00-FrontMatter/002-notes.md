## Writing Style

**Casual language**: This book was started as notes to myself as I stumbled through **learning** how to use *Psi4*. I wanted to build an exercise in visiualizing molecular orbitals but, as I realized how **easy** some calculations were, I decided to do **more**. Since it was written to me, by me, it has a casual and inconsistent **style**. You will see "I" and "we" mixed in with passive voice. I make no apologies. Feel free to **send me comments and corrections**. I do need an editor.

**Bold Text**: You will see many words in **bold face** fonts. I once took a course in student engagement and one recommendation was to intersperse bold **highlights** throughout a paragraph. This is apparently useful for helping students to **read**, especially now that we all have attention spans measured in **seconds** rather than **minutes**. I tried to keep the bold text on key words but often they are in patterns such as "**big**" and "**small**". In other places bold is used just because it had been a **while** since the last bold word. Please let me know if this **bold experiment** is helpful or annoying.

**Font Highlights**: There is a **code style** used throughout the book. It is rendered as a **monospace font** in red/pink when in a paragraph and as monospace font with a grey background when in blocks. It is used for code, text that is being quoted from text files, and for command line entries. **Italics** are used for the traditional scientific uses and also for filenames of applications such as *Psi4*.

**Line Numbers**: Many code listings include line numbers along the **left edge**. These are generated by the book itself and are not part of the text of the original file. I use them to refer to **specific lines** in discussions and to **quickly find** the relevant locations in enormous text files.

## AI Confessional

**I used an LLM system to adapt** a previous web book that I had made years ago. It featured a different computational chemistry system. Most of the text in this book is my original words, adapted to describe the new system. I cut and pasted from text produced by the LLM as I asked it questions about functions in Psi4. In the end there is a lot of LLM-generated text that has been added to the book. Almost all of the code was generated by the LLM and then editted by myself for simplicity. You can read a more fulsome **description of my AI crimes** below.

**Several years ago** I wrote a web book on using the [*GAMESS* computational chemistry package](https://www.msg.chem.iastate.edu/GAMESS/). I have not used it since I switched to a computer with an ARM processor. There are no pre-compiled builds available for consumer-grade ARM computers (I am using an Apple MacBook Air). I attempted to compile the applications from the source code and it was a complete fail. 

**Recently**, I have become a fan of LLM systems for assisting my work. After a fashionable period of eshewing it, I dipped my toes into the pool and found it inviting. The arrival of systems that can access my own files and develop persistent workflows and procedures (skills) has really changed things for me. I haven't used an agent yet, but I'll get there. **I asked my LLM system to help** with compiling *GAMESS* and it found all the problems. There were typographical errors in the make file,  issues with libraries on new MacOS computers, some outdated Fortran in the source code and a witches brew of other wierd issues. In the end I got it working. I would never have succeeded without my LLM assistant. I think a human expert would have lost patience with me. I added new pages to my book with instructions describing my convoluted compilation process. **The LLM system wrote** those two pages for me, and **it did a great job** of distilling a lengthy series of dead ends and restarts into a single step-by-step manual that I was able to use to repeat the compilation successfully. Still, it was a **lengthy process** and required skills that most students are unlikely to have.

I decided not to put my students through such a trial by fire. Also, it appears that *GAMESS* has not been updated since 2024 (I am writing this in November, 2026). I had compiled the 2023 version and requested the 2024 version to obtain source code that worked with a more recent Fortran compiler. No one has answered my requests. Is anyone still there?

I have also decided not to require students to install software. Half my students use iPads or phones as their primary computing device. I need something that can be **used via a web page** so that no one needs to install anything. *Python* and its vast ecosystem of tools can be run on websites like [**Google Colab**](https://colab.research.google.com). There are many computational chemistry packages available now as *Python* modules. One such system is ***Psi4***.

This book is largely a **rewrite** of my own original web book on using *GAMESS*. I had the LLM system criticize the content and organization of that book and it was brutal. **I used a LLM system extensively** in adapting the contents of the book and **rewriting** all the code from *Unix* tools and *GAMESS* input files to using the *Psi4* system via *Python* code. The LLM wrote **sophisticated code** that checked for errors and accounted for many caveates and edge cases. I was amazed! I had been working on learning *Psi4* in my spare time for the last three years and found the documentation to be opaque and useful examples and tutorials to be rare. I don't know where the training data came from, but the LLM was a true expert (in the humble eyes of a beginner like me). It was great, but was **a little too much**. I editted the code down to be a spare as I could. I want students to be able to interpret what the code is doing. I learned a lot about *Python* as I adapted the excellent code produced by the LLM and made my own **simple and clumsy** versions.

## Thoughts About the Future

**It's a new world**. I surrender. I, for one, welcome our new AI overlords. In all seriousness, **LLM systems can be very useful**. In this case, the code produced by the LLM can be easily tested, errors identified, and corrections made. Experimental values are known for the properties being calculated and large databases of benchmark values produced by the field of computational chemistry are available. There can be no halucinations **when the truth is known** to the 10{sup}`th` decimal place. 

I can see myself **accepting** student work that was produced with **LLM assistance** in the future. I will expect a detailed **confession** explaining the role of the LLM in the project, like the one I wrote above. What is **important** in any project is the **learning**. I learned so much about *Psi4* by examining the code produced by the LLM. I then queried the LLM for its **reasoning** and learned even more. I also learned lots about *Python* that I did not know before. I am a chemist, not a computer programmer. I feel that I could perform **basic calculations** using *Psi4* if I was dropped in front a computer all by myself. I also can now better **describe methods** that I should use in given situations and can better **evaluate** published work that includes computational chemistry. The words in this book did not teach me anything; **the struggle** to get these calculations working with much simpler code than the LLM handed me while also using methods that did not exceed the meagre computational resources available on a laptop computer or in a Google Colab container **is where the learning happened**. I could probably have had the LLM system write a similar book all by itself. If I had done that, I would not be able to answer any questions about the subject; and I'm sure that you will have questions.
